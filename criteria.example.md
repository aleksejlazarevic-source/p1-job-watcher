# Job criteria (example)

This is a sample criteria file with made-up preferences, so you can see the
shape of the input without any personal details. Copy it to `criteria.md`
and edit it to match your own situation — the agent re-reads it on every run,
no code changes needed.

## Goal
Find student/part-time jobs (city X, reachable by bike/bus, or remote) that
build a specific skill set. AI-relevance decides priority in this example;
swap in whatever matters to you.

## Tier 1: message me immediately
Job directly involves AI, automation, coding, or data:
- AI training/evaluation, annotation, prompt work
- Junior dev, scripting, automation, no-code tools, IT
- Content/video/marketing where AI tools are used or welcome
Keywords: artificial intelligence, AI, ChatGPT, automation, programming,
Python, data, digital marketing, video editing, content, IT support

## Tier 2: daily digest
Jobs that build skills that stack with the Tier 1 list:
- Tech/customer support (debugging, understanding what gets automated)
- Translation/copywriting (language precision = prompting)
- Tutoring/teaching (explaining clearly, teaching mindset)
- Research, admin or data work at small companies or startups
  (repetitive processes that could be automated)
Bonus: remote, small team, startup, independent work

## Tier 3: weekly roll-up only
Any other job that fits your physical/schedule constraints.

## Exclude
Example only — replace with your own constraints:
exclude anything that conflicts with your physical limits or availability.
If unclear, flag it; don't drop it.

## Output per job
Title, pay, hours, location/remote, link, and one line on
WHY it fits: which skill it builds.
